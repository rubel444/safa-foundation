# আমাদের সমিতি — হিসাব খাতা (ওয়েবসাইট)

এইটা তোমার সমিতির জন্য একটা পূর্ণাঙ্গ ওয়েবসাইট:
- **সবাই (পাবলিক লিংক)** দেখতে পারবে: প্রতিটা সদস্যের ছবি, নাম, মাসভিত্তিক জমা, বর্তমান ব্যালেন্স, সর্বমোট তহবিল।
- **শুধু তুমি (এডমিন)** ইউজারনেম/পাসওয়ার্ড দিয়ে লগইন করে: নতুন জমার এন্ট্রি দেয়া, নতুন সদস্য যোগ করা, কেউ চলে গেলে মার্ক করা, প্রজেক্টের লাভ সব সদস্যের মধ্যে ভাগ করে দেয়া — এসব করতে পারবে।

সম্পূর্ণ ফ্রি খরচে চলবে (Vercel + Supabase দুইটারই ফ্রি প্ল্যান যথেষ্ট)।

নিচের ধাপগুলো একটার পর একটা করলেই ওয়েবসাইট লাইভ হয়ে যাবে। কোনো কোডিং জানার দরকার নাই, শুধু copy-paste করতে হবে।

---

## ধাপ ১: Supabase এ ডাটাবেজ বানানো (ফ্রি)

1. https://supabase.com এ যাও, "Start your project" চেপে email দিয়ে সাইন আপ করো।
2. একটা নতুন Project বানাও (নাম যা খুশি দাও, যেমন `shomiti-hisab`)। একটা ডাটাবেজ পাসওয়ার্ড চাইবে — সেটা কোথাও নোট করে রাখো (এটার আর দরকার হবে না বেশি)।
3. Project তৈরি হতে ১-২ মিনিট সময় লাগবে।
4. বাম পাশের মেনু থেকে **SQL Editor** এ ক্লিক করো।
5. এই প্রজেক্টের সাথে থাকা `supabase-schema.sql` ফাইলটা খুলে পুরো কনটেন্ট কপি করে SQL Editor এ পেস্ট করো, তারপর **Run** চাপো। এতে করে তোমার সব টেবিল (members, transactions, investments) তৈরি হয়ে যাবে।
6. বাম মেনু থেকে **Project Settings > API** এ যাও। দুইটা জিনিস কপি করে রাখো:
   - **Project URL** (যেমনঃ `https://xxxxx.supabase.co`)
   - **service_role key** (এইটা গোপন রাখতে হবে, কাউকে শেয়ার করবা না)

## ধাপ ২: কোড GitHub এ আপলোড করা

1. https://github.com এ একটা ফ্রি অ্যাকাউন্ট বানাও (না থাকলে)।
2. নতুন একটা repository বানাও (Public বা Private, দুইটাই চলবে), নাম দাও `shomiti-hisab`।
3. এই পুরো ফোল্ডারটা (যেটা আমি দিয়েছি) সেই repository তে আপলোড করো। সবচেয়ে সহজ উপায়:
   - GitHub এর repository পেইজে "uploading an existing file" লিংকে ক্লিক করে পুরো ফোল্ডার ড্র্যাগ-ড্রপ করে দাও, "Commit changes" চাপো।
   - (চাইলে GitHub Desktop অ্যাপ ব্যবহার করেও করতে পারো)

## ধাপ ৩: Vercel এ Deploy করা (ফ্রি হোস্টিং)

1. https://vercel.com এ যাও, "Sign Up" এ ক্লিক করে **Continue with GitHub** দিয়ে সাইন আপ করো (এতে GitHub এর সাথে সরাসরি যুক্ত হয়ে যাবে)।
2. Dashboard এ "Add New... > Project" এ ক্লিক করো।
3. তোমার `shomiti-hisab` repository টা import করো।
4. Deploy করার আগে **Environment Variables** সেকশনে গিয়ে এই ৫টা ভ্যারিয়েবল যোগ করো:

   | Name | Value |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | Supabase থেকে পাওয়া Project URL |
   | `SUPABASE_SERVICE_ROLE_KEY` | Supabase থেকে পাওয়া service_role key |
   | `ADMIN_USERNAME` | তোমার পছন্দমতো একটা ইউজারনেম (যেমন `admin`) |
   | `ADMIN_PASSWORD` | তোমার পছন্দমতো একটা শক্ত পাসওয়ার্ড |
   | `ADMIN_SECRET` | যেকোনো লম্বা র‍্যান্ডম লেখা (যেমন `a8f92kd82jd9182jd`) |

5. **Deploy** চাপো। ১-২ মিনিটের মধ্যে তোমার ওয়েবসাইট লাইভ হয়ে যাবে, একটা লিংক পাবে (যেমন `shomiti-hisab.vercel.app`)। এইটাই তোমার সমিতির সবার শেয়ার করার লিংক।

## ধাপ ৪: প্রথমবার ব্যবহার শুরু করা

1. তোমার লাইভ লিংকে গিয়ে `/admin` যোগ করো (যেমন `shomiti-hisab.vercel.app/admin`), ADMIN_USERNAME এবং ADMIN_PASSWORD দিয়ে লগইন করো।
2. **"সদস্যগণ"** ট্যাব থেকে তোমার ২১ জন সক্রিয় সদস্যকে একে একে যোগ করো (যাদের আগের ব্যালেন্স আছে, সেই "Previous Amount" বসিয়ে দাও)।
3. প্রতি মাসে যখন কেউ টাকা জমা দিবে, **"জমা এন্ট্রি"** ট্যাব থেকে entry দিয়ে দাও।
4. কোনো প্রজেক্টে বিনিয়োগ করে লাভ হলে, **"লাভ / বিনিয়োগ"** ট্যাব থেকে এক ক্লিকেই সবার মধ্যে সমান ভাগ করে দিতে পারবে।
5. কেউ সমিতি ছেড়ে গেলে "সদস্যগণ" ট্যাব থেকে তাকে "চলে গেছেন" মার্ক করে দিও (তার ইতিহাস থেকে যাবে, কিন্তু নতুন হিসাবে যোগ হবে না)।

## ছবি কীভাবে যোগ করব?

সদস্যের ছবি সরাসরি আপলোডের ব্যবস্থা এখনো নাই — তার বদলে একটা **ছবির লিংক (URL)** বসাতে হবে। সহজ উপায়:
- ছবি [imgur.com](https://imgur.com) এ আপলোড করে সেখান থেকে "Direct Link" কপি করে "সদস্যগণ" ফর্মের "ছবির লিংক" ঘরে বসিয়ে দাও।
- ছবি না দিলেও সমস্যা নাই — নামের প্রথম অক্ষর দিয়ে একটা সুন্দর আইকন দেখাবে।

(পরে চাইলে সরাসরি ছবি আপলোডের ফিচারও যোগ করে দেয়া যাবে — শুধু বলো।)

## নতুন আপডেট: বকেয়া (Due) ট্র্যাকিং ও অনুপাতে লাভ বন্টন

এই ভার্সনে ৩টা নতুন জিনিস যোগ হয়েছে:

1. **টার্গেট এমাউন্ট / বকেয়া**: "সদস্যগণ" ট্যাবের টেবিলে প্রতিটা সদস্যের পাশে এখন "টার্গেট এমাউন্ট" ঘর আছে — এখানে তুমি নিজে বসাবে "এই মাস পর্যন্ত সদস্যটার পুরোপুরি ক্লিয়ার থাকলে কত টাকা জমা থাকার কথা" (যেমন 51000)। এটা তুমি যেকোনো সময় বদলাতে পারবে (মাস শেষে বাড়িয়ে দিও)। যার প্রকৃত জমা এই টার্গেটের চেয়ে কম, তার নামের পাশে লাল রঙে "বকেয়া" দেখাবে — পাবলিক পেইজ এবং এডমিন প্যানেল দুই জায়গাতেই।
2. **অনুপাতে লাভ বন্টন**: আগে প্রজেক্টের লাভ সব সদস্যের মধ্যে সমান ভাগ হতো। এখন থেকে — যেই তারিখে বন্টন করবে, সেই তারিখ পর্যন্ত যার যত টাকা জমা আছে, তার সেই অনুপাতে লাভ ভাগ হবে (বেশি জমাদাতা বেশি পাবে)।
3. **সদস্যের নামে ক্লিক করলে বিস্তারিত**: এখন সদস্যের ছবি/নামের উপর ক্লিক করলেই মোট জমা, লাভের ভাগ, টার্গেট, যোগদানের তারিখ এবং তারিখ-ভিত্তিক পুরো লেনদেনের তালিকা দেখাবে।

### এই আপডেট চালু করতে যা করতে হবে (একবারই):

**ধাপ ১ — Supabase এ নতুন কলাম যোগ করা:**
Supabase Dashboard → SQL Editor এ গিয়ে এই লাইনটা Run করো:
```sql
alter table members add column if not exists target_amount numeric default 0;
```

**ধাপ ২ — নতুন কোড আপলোড করা:**
এই নতুন zip এর ফাইলগুলো (বিশেষ করে বদলানো ফাইলগুলো: `app/page.js`, `app/MemberCard.js`, `app/globals.css`, `app/admin/page.js`, `app/api/investments/route.js`, `app/api/members/route.js`, `app/api/members/[id]/route.js`, `app/api/deposits/route.js`, `lib/supabaseAdmin.js`, `lib/helpers.js`) GitHub repo তে গিয়ে পুরনোগুলোর বদলে আপলোড করে দাও (Add file → Upload files, তারপর একই নামের ফাইল উপরে ফেললে replace হয়ে যাবে), Commit করো। Vercel automatically নতুন deploy করবে।

### ছবি (Photo) সম্পর্কে

ছবি লিংক কাজ না করলে নিচের পদ্ধতিতে সঠিক direct-link বের করো:
- ছবি [imgur.com](https://imgur.com) এ আপলোড করার পর, আপলোড হওয়া ছবিটার উপর **right-click করে "Copy image address"** সিলেক্ট করো (পেইজের লিংক না, সরাসরি ছবির লিংক)। এই লিংকটা `.jpg`/`.png` দিয়ে শেষ হওয়ার কথা, যেমন: `https://i.imgur.com/xxxxxxx.jpg`
- এখন ভুল/ভাঙা লিংক দিলেও সমস্যা নাই — সিস্টেম automatically সুন্দর করে নামের প্রথম অক্ষর দেখিয়ে দিবে।

## নতুন আপডেট ২: বাগ ফিক্স + বাল্ক টার্গেট + এক্সেল রিপোর্ট ডাউনলোড

1. **বাগ ফিক্স**: বকেয়া (Due) হিসাব করার সময় আগের ব্যালেন্স (Previous Amount) বাদ পড়ে যাচ্ছিল, এখন ঠিক করা হয়েছে — এখন due = টার্গেট − (আগের ব্যালেন্স + সব জমা)।
2. **সবাইকে একসাথে টার্গেট দেয়া**: "সদস্যগণ" ট্যাবের একদম উপরে এখন একটা বক্স আছে — এক জায়গায় একটা সংখ্যা বসিয়ে "সবার টার্গেট আপডেট করুন" চাপলেই সব সক্রিয় সদস্যের টার্গেট এমাউন্ট একসাথে বদলে যাবে (একজন একজন করে বসাতে হবে না)।
3. **এক্সেল ডাউনলোড (নতুন ট্যাব "রিপোর্ট/ডাউনলোড")**:
   - একজন নির্দিষ্ট সদস্যের সম্পূর্ণ (তারিখ-ভিত্তিক) হিসাব
   - সব সদস্যের একসাথে সারসংক্ষেপ
   - একটা নির্দিষ্ট মাসের রিপোর্ট
   - একটা নির্দিষ্ট বছরের রিপোর্ট (সদস্য x মাস ম্যাট্রিক্স, ঠিক পুরনো এক্সেল শীটের মতো দেখতে)

### চালু করতে যা করতে হবে:
GitHub এ গিয়ে এই নতুন zip এর সব ফাইল (বিশেষ করে `package.json`, `lib/helpers.js`, `lib/exportHelpers.js` (নতুন ফাইল), `app/admin/page.js`, `app/api/members/bulk-target/route.js` (নতুন ফাইল)) upload করে Commit করো। Supabase এ নতুন কোনো SQL লাগবে না এইবার। Vercel automatically deploy করে নিবে।

## নতুন আপডেট ৩: ম্যানুয়াল লাভ বন্টন + সর্বমোট বকেয়া

1. **ম্যানুয়াল লাভ বন্টন মোড**: "লাভ / বিনিয়োগ" ট্যাবে এখন দুইটা মোড আছে —
   - **স্বয়ংক্রিয়**: বন্টনের তারিখ পর্যন্ত সিস্টেমের কাছে থাকা জমার তথ্য দিয়ে অনুপাতে ভাগ করে (আগের মতোই)
   - **ম্যানুয়াল**: যদি সেই পুরনো সময়ের প্রকৃত জমার তথ্য সিস্টেমে না থাকে (যেমন লাম্প-সাম "আগের ব্যালেন্স" হিসেবে ঢোকানো ছিল), তাহলে এই মোডে প্রতিটা সক্রিয় সদস্যের জন্য তুমি নিজে হিসাব করে সরাসরি টাকার অংক বসিয়ে দিতে পারবে — সিস্টেম শুধু সেটাই প্রতিটা সদস্যের হিসাবে যোগ করে দিবে।
2. **সর্বমোট বকেয়া**: পাবলিক পেইজে এবং এডমিন প্যানেলের "সদস্যগণ" ট্যাবে এখন একটা আলাদা জায়গায় সব সদস্য মিলিয়ে মোট কত টাকা বকেয়া আছে সেটা একসাথে দেখাবে (কেউ বকেয়া না থাকলে এই জায়গাটা দেখাবে না)।
3. জমা (deposit) আর লাভ (profit) সবসময় আলাদা রঙে/আলাদা লাইনে দেখানো হয় (কখনো একসাথে মিলিয়ে দেখানো হয় না) — সদস্যের কার্ডে "বিস্তারিত" খুললে "মোট জমা" ও "লাভের ভাগ" সবসময় আলাদা দেখা যাবে।

### চালু করতে: 
GitHub এ গিয়ে এই নতুন zip এর সব ফাইল (বিশেষ করে `app/admin/page.js`, `app/page.js`, `app/globals.css`, `app/api/investments/route.js`) upload করে Commit করো। কোনো নতুন SQL লাগবে না।

## নতুন আপডেট ৪: জমা/লাভ আলাদা দেখানো + এন্ট্রি এডিট করার সুবিধা

1. **মূল ভিউতে শুধু "মোট জমা"**: সদস্যদের কার্ডে এখন প্রথমেই শুধু **"মোট জমা"** (আগের ব্যালেন্স + এ পর্যন্ত করা সব জমা, লাভ বাদে) দেখাবে। "বিস্তারিত দেখুন" এ ক্লিক করলে তখন মোট জমা, লাভের ভাগ, এবং সর্বমোট (জমা+লাভ) — এই তিনটাই আলাদা আলাদা করে একসাথে দেখাবে।
2. **এন্ট্রি এডিট করা**: এডমিন প্যানেলের "সব লেনদেন" ট্যাবে এখন প্রতিটা এন্ট্রির পাশে "এডিট" বাটন আছে — এতে ক্লিক করলে তারিখ, মাস, পরিমাণ, মন্তব্য সরাসরি বদলে "সেভ" করা যাবে। ভুল এন্ট্রি দিলে এখন থেকে মুছে আবার নতুন করে দেয়া লাগবে না, সরাসরি এডিট করা যাবে।

### চালু করতে:
GitHub এ গিয়ে নতুন zip এর ফাইলগুলো (`lib/helpers.js`, `app/MemberCard.js`, `app/globals.css`, `app/admin/page.js`) upload করে Commit করো।
